# NumPy & Pandas + Titanic Exploration

حلول الأجزاء 1-3 (NumPy، Pandas، الفلترة) + تقرير استكشاف كامل لداتاسيت
**Titanic** (الجزء 4)، في نوتبوك واحد منفّذ بالكامل مع ظهور كل النتائج تحت
الخلايا.

## الملف الرئيسي

- **`titanic_numpy_pandas.ipynb`** — النوتبوك الكامل (الحلول + التقرير + الخلاصة)،
  منفّذ والنتائج مضمّنة.
- **`titanic_numpy_pandas.html`** — نسخة HTML جاهزة للعرض بدون تشغيل (افتحها
  بالمتصفح مباشرة).

## المحتوى

**الجزء 1 — NumPy:** إنشاء مصفوفة 1..20 و`reshape` إلى 4×5؛ جمع/طرح/ضرب عنصر
بعنصر عبر Broadcasting بدون حلقات؛ مقارنة `np.mean/np.std` مع دوال يدوية على نفس
الأرقام (متطابقة تمامًا)؛ و Slicing لاستخراج صف وعمود ومصفوفة فرعية.

**الجزء 2 — Pandas:** إنشاء `Series` وطباعة خصائصها؛ بناء `DataFrame` لبيانات 5
طلاب؛ تحميل Titanic والاستكشاف الأولي (`head`, `shape`, `dtypes`, `describe`,
`isnull().sum()`).

**الجزء 3 — الفلترة:** عرض عمود العمر؛ الركاب فوق 40؛ الإناث الناجيات؛ الترتيب
حسب العمر (أكبر 10)؛ واستخدام `loc` لعرض صفوف وأعمدة محددة.

**الجزء 4 — تقرير Titanic:** نظرة عامة على الأعمدة، القيم المفقودة، تفسير
`describe`، والإجابة بالكود على الأسئلة الاستكشافية، ثم خلاصة بأهم 3 ملاحظات.
